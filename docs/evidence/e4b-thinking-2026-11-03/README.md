# E4B native thinking off/on: filtered old-task diagnostic evidence

Three previously inspected SWE-bench Lite tasks, two modes, six ordered single-seed attempts. Both modes share the original private A prompt/config/Skill; only the effective native think Boolean changes. This is a purposive development diagnostic, not unseen confirmation, a population estimate or an official Docker/QAT/vLLM/Kaggle score.

Provider eval_count includes generated thinking. Native thought presence/characters are observable; a separate reasoning-token count is not inferred. Provider durations in call usage are original nanoseconds; aggregate durations are converted seconds. HTTP/process wall time is separate. Every done_reason and length stop is retained, regardless of remaining time/turn/tool budget.

Typed Skill/test clues are not proof of current target-test success. Zero-selected tests, collection failures, syntax-only checks and model claims of implicit checkpoints do not establish a closed verification loop. Fresh independent fixed-node grading determines outcomes.

Run python verify.py for hashes, three pairs/six samples, patch binding, fixed test outcomes, numeric reasoning observations and usage units. It reruns no models/tests and cannot authenticate the withheld private transcript independently. All six numeric/grade/patch-SHA samples remain even if a patch must be withheld for privacy. Exact agent reproduction requires the authorized private gemma-agent snapshot.

Private config/prompts/Skill/source, raw native thinking, raw requests/responses/traces, command stdout, host pytest logs, gold/test patch bodies and hints are excluded. Current thinking-study service fingerprint/contracts are used; prior live PID evidence is not substituted. Upstream licenses and source links for the reused public snapshots are in notices/.
